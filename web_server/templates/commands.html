🔄 Official Tournament Match Lifecycle

How matches flow from creation to Challonge bracket sync

1

Match Created

Organizer runs /event-create. Bot renders custom poster with team names, logs match to database, and posts to #schedule.

2

Staff Claim

Judges and Recorders claim duty by clicking Take Schedule or Record buttons on the schedule embed.

3

T-30 Presence Check

At T-30 minutes, confirmation ping is dispatched to the ticket. If unconfirmed by T-20m, backup judges are alerted automatically.

4

Scores & Sync

Judge runs /event-result with screenshots, then /upload-score pushes match outcomes straight to Challonge.

/settings add 👑 Administrator

Initializes and binds complete server-wide role mappings, operational channels, and custom organization branding into the database.

Parameters & Options:
admin_role Role (Required) Server Head Administrator role
organizer_role Role (Required) Tournament Organizer staff role
judge_role Role (Optional) Official match referee / judge role
rules_channel Channel (Optional) Channel where official tournament rules are posted
organization_name String (Optional) Custom esports org or clan branding title
/settings add admin_role:@TournamentAdmin organizer_role:@Organizer judge_role:@Judge organization_name:"Apex Champions League"
/settings edit 👑 Administrator

Modifies existing server-wide configurations, Google Sheet roster sync links, result channels, or system branding without overwriting other parameters.

Parameters:
google_sheet_link URL (Optional) Direct CSV or Google Sheet URL for player/team rosters
results_channel Channel (Optional) Channel where finalized match results embeds are posted
player_info_format Select (Optional) Format layout: 1 vs 1, 2 vs 2, 4 vs 4, 5 vs 5
/settings edit google_sheet_link:https://docs.google.com/spreadsheets/d/... player_info_format:"5 vs 5"
/settings show 👑 Administrator

Displays a rich overview embed of all active role IDs, operational channels, database sync status, and active Google Sheet integrations.

/settings show
/test_channels 👑 Administrator

Performs a comprehensive diagnostic test verifying bot permissions (Send Messages, Embed Links, Attach Files, Manage Channels) across all configured channels.

/test_channels
/staff-update 👑 Administrator

Manually adjusts or overrides points and match officiating statistics for a Judge or Recorder on the staff leaderboard.

Parameters:
staff_member User (Required) Target Judge or Recorder member mention
points_delta Integer (Required) Number of points to add or subtract (e.g. +5, -2)
/staff-update staff_member:@JudgeAlex points_delta:5
/publish-rules 👑 Administrator

Formats, renders, and publishes official tournament rulebooks, match conduct policies, and penalty guidelines directly to the configured rules channel.

/publish-rules
/clear category 👑 Administrator

Safely purges completed or closed ticket channels inside a specified category to keep the Discord server organized.

Parameters:
category_name Category (Required) Target category to purge closed match ticket channels
/clear category category_name:"Closed Match Tickets"
/clear cache 👑 Administrator

Clears cached Challonge API brackets, active Google Sheet roster indexes, and reloads real-time data from primary sources.

/clear cache
/settings clean ⚠️ Danger / Admin

Resets all server role mappings, channels, and cached data back to default factory settings. Requires confirmation.

/settings clean
/tournament add 🛡️ Organizer

Registers a new tournament championship into the database with Challonge bracket links, match channels, and ticket category routing.

Parameters:
tournament_name String (Required) Official championship title
bracket_link URL (Required) Challonge bracket or custom web bracket URL
open_category Category (Optional) Discord category where new match tickets are opened
auto_room Boolean (Optional) Automatically create match ticket rooms from Challonge
/tournament add tournament_name:"Valorant Masters Season 4" bracket_link:https://challonge.com/val_s4 auto_room:True
/tournament edit 🛡️ Organizer

Modifies existing tournament configuration including active status (pending, active, completed), sheet links, or auto-room sweeps.

/tournament edit tournament_name:"Valorant Masters" state:active
/tournament list / info 🛡️ Organizer

Lists all tournaments registered on this server, or retrieves comprehensive details (IDs, channel bindings, state, participants) for a specific tournament.

/tournament list • /tournament info tournament_name:"Valorant Masters"

Controls the automated match ticket creation engine. /auto_room run immediately sweeps the Challonge bracket for open matches and spawns private channels for captains and judges.

/auto_room run • /auto_room toggle status:True

/exchange 🛡️ Organizer

Replaces or swaps an assigned Judge or Recorder on an active match event without deleting the match record.

/event-create ⚖️ Judge & Staff

Creates a scheduled match event. Generates a custom high-resolution match poster graphic with auto-scaling font margins, logs the match to Supabase, and posts the schedule embed.

Parameters:
team_1 String / Member (Required) First team name or Captain mention
team_2 String / Member (Required) Second team name or Captain mention
match_time String (Required) Scheduled time (e.g. 20:30 UTC or timestamp)
round_name String (Optional) e.g. Round 1, Semi-Finals, Grand Final
/event-create team_1:"Team Alpha" team_2:"Team Phantom" match_time:"19:00 UTC" round_name:"Quarter-Final"
/event-result ⚖️ Judge & Staff

Enters official verified match results, uploads screenshot proof, records judge points on the staff leaderboard, and publishes a finalized victory embed.

Parameters:
winner String / Mention (Required) Winning team name or captain
score String (Required) Final match score (e.g. 2 - 1, 13 - 9)
proof_image Attachment (Optional) Screenshot of end-game scoreboard
/event-result winner:"Team Alpha" score:"2 - 0"
/upload-score ⚖️ Judge & Staff

Syncs match outcomes directly to the Challonge bracket via live autocompletion dropdown. Advances the winning team to the next round immediately.

Parameters:
winner Dropdown (Required) Autocompleted list of active matches in bracket
winner_score Integer (Required) Sets won by the winning team (e.g. 2)
loser_score Integer (Required) Sets won by the losing team (e.g. 0)
/upload-score winner:"Team Alpha (vs Team Omega)" winner_score:2 loser_score:1
